      Frequently Asked Questions

      What is Open Swiss Tax Statement?

      A free, open-source tool that generates official eCH-0196 tax statement PDFs from your broker's CSV export. Swiss cantonal tax authorities process these electronically — exactly like the statements brokers charge CHF 85–100 for.

      How does this work?

      Switzerland uses an open standard called eCH-0196 for electronic tax statements. This app reads your broker's transaction data, enriches it with official ESTV tax values and exchange rates, then generates a PDF with machine-readable barcodes that your tax office can scan — the same format your broker would produce.

      Does any of my data leave my computer?

      No. The app runs 100% offline. All parsing, enrichment, and PDF generation happens locally. There are no network calls, no analytics, no telemetry. You can verify this — the test suite includes an automated check that scans all source code for network imports.

      Where is my data stored?

      Everything is stored in ~/Documents/OpenSwissTaxStatement/. Generated PDFs and input files are archived in the statements/ subfolder. All data stays on your computer and can be deleted manually at any time.

      Will this work for next year's tax statement?

      The app needs yearly updates for ESTV exchange rates and the ICTAX Kursliste (official security tax values). These are bundled with each release. As long as the eCH-0196 standard remains unchanged and updated data is available, it will work for future years.

      Which brokers are supported?

      Currently Swissquote (full support). More Swiss brokers are planned — see the landing page for the roadmap.

      What files are stored locally?

      Three categories in ~/Documents/OpenSwissTaxStatement/: statements/ — generated PDFs and copies of your input files, organized by year. data/ — user-provided Kursliste overrides (only when the bundled data doesn’t cover your tax year). preferences.json — app preferences like your saved profile.
